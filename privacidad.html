Política de privacidad

Última actualización: 13 de noviembre de 2026

El Publicador alan.hiskin (“la aplicación”) es una herramienta de uso personal que su dueño usa para preparar sus propios videos y conectarlos con su canal de YouTube. La aplicación funciona de forma local en la computadora de quien la usa. No tiene servidores propios, no tiene cuentas de usuario propias y no está disponible para el público.

Uso de los Servicios de la API de YouTube

La aplicación usa los Servicios de la API de YouTube para conectarse con la cuenta de YouTube del usuario. Al usar la aplicación, aceptás los Términos del Servicio de YouTube. Google trata los datos según la Política de Privacidad de Google.

Estado actual de la aplicación

  • YouTube: la aplicación se conecta para identificar el canal. La subida de videos está en preparación y todavía no está activa.
  • Otras plataformas: la aplicación no se conecta con ninguna otra red social.

Qué información usa la aplicación

  • Datos del canal de YouTube: el identificador, el nombre y el nombre de usuario del canal conectado, para mostrar qué canal está conectado.
  • Credenciales de acceso de Google (tokens OAuth): necesarias para consultar YouTube en nombre del usuario. La aplicación nunca ve ni guarda la contraseña de Google: el inicio de sesión se hace en la página oficial de Google.
  • Textos de publicación: el título, la descripción y los hashtags que el usuario escribe en la aplicación para cada video.
  • Historial: el estado de preparación y aprobación de cada video, con sus fechas.

Subida de videos (cuando se active)

Cuando la subida de videos se active, la aplicación enviará a YouTube únicamente los videos que el usuario revise y apruebe en forma explícita, junto con el título, la descripción, los hashtags y la visibilidad que él elija. Guardará también el identificador que YouTube asigne a cada video subido. Para eso pedirá a Google, en la pantalla oficial de permisos, el permiso de subir videos a la cuenta del usuario.

Cómo se usa esa información

Solo para mostrar qué canal está conectado, preparar las publicaciones y, cuando la subida esté activa, publicar lo que el usuario aprueba. La aplicación no usa los datos para publicidad, no crea perfiles, no vende datos y no los usa para ningún otro fin.

Dónde se guarda y con quién se comparte

  • La información se guarda solo en la computadora del usuario. La aplicación no envía datos a servidores propios ni a terceros.
  • La única comunicación externa de la aplicación es con Google y YouTube, a través de sus servicios oficiales, para hacer lo que el usuario pide.
  • La aplicación no muestra publicidad, no permite que terceros muestren contenido o anuncios y no usa cookies ni tecnologías de seguimiento.

Cuánto tiempo se conserva

Las credenciales de acceso se conservan en la computadora del usuario hasta que él desconecta la cuenta desde la aplicación o revoca el acceso desde Google. Al tocar “Desconectar”, la aplicación le pide a Google que revoque el permiso y borra las credenciales de la computadora. Los textos y el historial se conservan en la computadora del usuario hasta que él los borre.

Cómo revocar el acceso

Podés quitarle a la aplicación el acceso a tu cuenta en cualquier momento desde la página de permisos de seguridad de Google, o con el botón “Desconectar” dentro de la aplicación.

Política de datos de las API de Google

El uso y la transferencia de la información recibida de las API de Google cumplen con la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de Uso Limitado.

Este sitio web

Estas páginas informativas están alojadas en GitHub Pages. No usan cookies, analíticas ni contenido de terceros. GitHub puede registrar datos técnicos de las visitas según su declaración de privacidad.

Cambios en esta política

Si cambia el uso de los datos o la aplicación se conecta con otras plataformas, esta página se actualizará antes de que el cambio entre en funcionamiento, con una nueva fecha de actualización.

Contacto

Para consultas o reclamos sobre esta política, podés abrir una consulta en la sección Issues del repositorio de este sitio en GitHub. Las consultas en esa sección son públicas: no incluyas datos personales.

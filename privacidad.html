Política de privacidad

Última actualización: 13 de noviembre de 2026

El Publicador alan.hiskin (“la aplicación”) es una herramienta de uso personal que su dueño usa para preparar sus propios videos y conectarlos con su canal de YouTube y sus cuentas de Instagram y TikTok. La aplicación funciona de forma local en la computadora de quien la usa. No tiene servidores propios, no tiene cuentas de usuario propias y no está disponible para el público.

Uso de los Servicios de la API de YouTube

La aplicación usa los Servicios de la API de YouTube para conectarse con la cuenta de YouTube del usuario. Al usar la aplicación, aceptás los Términos del Servicio de YouTube. Google trata los datos según la Política de Privacidad de Google.

Uso de las plataformas de Meta

La aplicación se conecta con Instagram mediante el inicio de sesión oficial de Meta (Facebook Login para empresas). Meta trata los datos según su Política de privacidad, y la aplicación cumple las Condiciones de la Plataforma de Meta.

Uso de TikTok

La aplicación se conecta con TikTok mediante el inicio de sesión oficial de TikTok (Login Kit) y su API oficial de publicación de contenido. TikTok trata los datos según su Política de privacidad, y la aplicación cumple las Condiciones para desarrolladores de TikTok.

Estado actual de la aplicación

  • YouTube: la aplicación se conecta para identificar el canal y para subir los videos que el usuario aprueba. La subida real solo funciona si el usuario la activa en la aplicación; si no, todo se simula sin enviar nada a YouTube.
  • Instagram: la aplicación se conecta para identificar la cuenta que el usuario autoriza y para publicar los Reels que el usuario aprueba. La publicación real solo funciona si el usuario la activa en la aplicación; si no, todo se simula sin enviar nada a Meta.
  • TikTok: la aplicación se conecta para identificar la cuenta y para enviar como borrador a la bandeja de TikTok los videos que el usuario aprueba. La aplicación nunca publica en TikTok: el usuario termina cada publicación en la app de TikTok. El envío solo funciona si el usuario lo activa en la aplicación.
  • Otras plataformas: la aplicación no se conecta con ninguna otra red social.

Qué información usa la aplicación

  • Datos del canal de YouTube: el identificador, el nombre y el nombre de usuario del canal conectado, para mostrar qué canal está conectado.
  • Credenciales de acceso de Google (tokens OAuth): necesarias para consultar YouTube en nombre del usuario. La aplicación nunca ve ni guarda la contraseña de Google: el inicio de sesión se hace en la página oficial de Google.
  • Datos de la cuenta de Instagram: el identificador, el nombre de usuario y el nombre de la cuenta autorizada, para mostrar qué cuenta está conectada.
  • Credencial de acceso de Meta: necesaria para consultar Instagram en nombre del usuario, limitada a la cuenta que él elige al conectar. La aplicación nunca ve ni guarda la contraseña de Facebook ni de Instagram: el inicio de sesión se hace en la página oficial de Meta.
  • Datos de la cuenta de TikTok: el identificador y el nombre visible de la cuenta autorizada, para mostrar qué cuenta está conectada.
  • Credencial de acceso de TikTok: necesaria para enviar borradores en nombre del usuario. La aplicación nunca ve ni guarda la contraseña de TikTok: el inicio de sesión se hace en la página oficial de TikTok.
  • Textos de publicación: el título, la descripción y los hashtags que el usuario escribe en la aplicación para cada video.
  • Historial: el estado de preparación, aprobación y publicación de cada video, con sus fechas, el identificador y el enlace que YouTube o Instagram asignan a cada publicación, el identificador de cada envío de borrador a TikTok, y la marca que el usuario agrega cuando ya publicó un video a mano.
  • Publicaciones recientes de Instagram (solo para evitar duplicados): antes de reintentar una publicación, la aplicación consulta el estado del envío en curso y los últimos Reels de la cuenta (identificador, texto, fecha y enlace) para comprobar si ya se publicó. Esa información se usa en el momento y no se guarda.

Subida de videos

Con el permiso de subir videos que el usuario otorga en la pantalla oficial de Google, la aplicación envía a YouTube únicamente los videos que el usuario revisa y aprueba en forma explícita, uno por uno. Con cada video envía el título, la descripción, los hashtags y la visibilidad (privado, no listado o público) que el usuario elige al aprobar. Después de subirlo, consulta a YouTube el estado y la visibilidad del video para mostrárselos al usuario.

Publicación de Reels en Instagram

Con el permiso de publicar que el usuario otorga en la pantalla oficial de Meta, la aplicación envía a Instagram únicamente los videos que el usuario revisa y aprueba en forma explícita, uno por uno, junto con el texto (descripción y hashtags) que él revisa. El video se envía directamente desde la computadora del usuario a Meta, con la carga oficial de Meta.

Los Reels se publican en el perfil y los pueden ver los seguidores y el público: Instagram no ofrece publicación privada.

Envío de borradores a TikTok

Con el permiso que el usuario otorga en la pantalla oficial de TikTok, la aplicación envía a la bandeja de TikTok, como borrador, únicamente los videos que el usuario aprueba, uno por uno, directamente desde su computadora. TikTok no recibe el texto por esta vía: el usuario lo copia y lo agrega en la app al terminar la publicación. Para no duplicar envíos, la aplicación consulta a TikTok el estado de cada envío. Un borrador no es público hasta que el usuario lo publica en la app de TikTok.

Cómo se usa esa información

Solo para mostrar qué cuentas están conectadas, preparar las publicaciones y publicar lo que el usuario aprueba. La aplicación no usa los datos para publicidad, no crea perfiles, no vende datos y no los usa para ningún otro fin.

Dónde se guarda y con quién se comparte

  • La información se guarda solo en la computadora del usuario. La aplicación no envía datos a servidores propios ni a terceros.
  • La única comunicación externa de la aplicación es con Google (YouTube), Meta (Instagram) y TikTok, a través de sus servicios oficiales, para hacer lo que el usuario pide.
  • Al conectar Instagram, Meta devuelve un código de un solo uso a través de la página meta-callback.html de este sitio, que lo reenvía de inmediato a la aplicación en la computadora del usuario. Esa página no guarda ni envía datos a ningún otro lugar.
  • La aplicación no muestra publicidad, no permite que terceros muestren contenido o anuncios y no usa cookies ni tecnologías de seguimiento.

Cuánto tiempo se conserva

Las credenciales de acceso y los datos de la cuenta conectada se conservan en la computadora del usuario hasta que él desconecta la cuenta desde la aplicación. Los textos y el historial de publicaciones se conservan en la computadora del usuario hasta que él los borre.

Cómo eliminar tus datos

La aplicación no tiene servidores: todos los datos están en la computadora de quien la usa, y se eliminan así:

  1. Credenciales y datos de la cuenta conectada: con el botón “Desconectar” de cada plataforma, la aplicación borra de la computadora la credencial y los datos de esa cuenta (identificador, nombre y nombre de usuario), y le pide a Google, a Meta o a TikTok que retire el permiso. En Instagram y TikTok, si la plataforma no confirma el retiro, la aplicación lo avisa. En YouTube la aplicación no muestra la respuesta de Google. En ambos casos, el paso 2 permite comprobar que el permiso se haya quitado.
  2. Permiso otorgado a la aplicación: se puede retirar en cualquier momento desde la página de permisos de seguridad de Google (YouTube) desde la configuración de integraciones comerciales de Facebook (Instagram) o desde la app de TikTok, en la sección de seguridad y permisos de apps de la configuración (TikTok).
  3. Textos e historial de publicaciones: se eliminan borrando la base de datos local de la aplicación, con la aplicación cerrada. Esto no borra las credenciales, que se guardan aparte.
  4. Publicaciones ya hechas en YouTube, Instagram o TikTok, y borradores en la bandeja de TikTok: se eliminan desde cada plataforma. La aplicación no los borra.

Para consultar sobre el borrado de datos, se puede escribir en la sección de contacto. Esos mensajes son públicos: no incluyas datos personales.

Política de datos de las API de Google

El uso y la transferencia de la información recibida de las API de Google cumplen con la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de Uso Limitado.

Este sitio web

Estas páginas informativas están alojadas en GitHub Pages. No usan cookies, analíticas ni contenido de terceros. La página meta-callback.html solo contiene un script que reenvía la conexión de Meta a la aplicación local. GitHub puede registrar datos técnicos de las visitas según su declaración de privacidad.

Cambios en esta política

Si cambia el uso de los datos o la aplicación se conecta con otras plataformas, esta página se actualizará antes de que el cambio entre en funcionamiento, con una nueva fecha de actualización.

Contacto

Para consultas o reclamos sobre esta política, incluidas las solicitudes sobre el borrado de datos, podés abrir una consulta en la sección Issues del repositorio de este sitio en GitHub. Las consultas en esa sección son públicas: no incluyas datos personales.
